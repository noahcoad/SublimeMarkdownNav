# 0.2.0

Both commands now remember where you left off, and the memory survives a restart.

## What's new

### Jump to Header remembers the whole chain, not just the leaf

Drill down `## Monday` → `### Standup` → `#### Blockers` and reopening the panel highlights each step
of that path by depth, instead of only the last header you landed on.

A renamed ancestor no longer resets the memory — it falls back to the previous containment heuristic
and keeps as much of the chain as still matches.

### Find Tag remembers too

It stores the tag *and* the label you picked, and only preselects a match when the remembered tag is
the one you're looking at now.

### The memory survives closing the file and restarting Sublime

Previously the last pick lived in a dict keyed on view id, so it was lost on plugin-host restart —
and on merely closing and reopening the file, since view ids aren't stable.

State now goes in `Packages/User/Markdown Nav.state.json`, keyed on file path. That's the same folder
your settings live in, so whatever syncs those between machines carries this too. Delete the file to
forget everything.

New setting **`persist_last_header`** (default `true`). Set it to `false` and the memory lasts only
for the session, per view, with nothing written to disk. Unsaved buffers are always session-only —
there's no path to key them on.

Writes are atomic and coalesced to about one per two seconds of jumping, 200 files are kept, and an
unreadable state file reports to the status bar and resets itself rather than breaking both commands.
